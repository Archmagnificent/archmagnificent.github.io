Game Design | Monsterful Tavern

Monsterful Tavern

A fantasy tavern simulator with TCG elements

Project type: Game · Role: Gameplay Designer · Status: In production

Visit site

Overview

Monsterful Tavern is a story-driven tavern simulator, set in a fantasy world. The players step into the shoes of a tavern keeper managing his inherited tavern, serving fantasy monsters. As they follow the plot of the game, they will meet many fantasy creatures and learn about their daily lives in the underground cavern. The game utilizes trading card game elements. Players serve drinks and dishes to the clients by playing cards, representing various recipes and the tavern keeper's actions.

Responsibilties

During my internship at Z'Serca studio I contributed to the project through:

  • Designing game systems
  • Designing gameplay mechanics
  • Designing control schemes
  • Designing user interface layouts
  • Designing quests
  • Writing game dialogue
  • Writing story elements
  • Collecting and analysing playtesters' data
  • Collaborating with other teams
  • Creating documentation used to develop tools
  • Translation work

Outcome and Reflection

This experience allowed me to immerse myself in a professional game development environment. I’ve dedicated this time to sharpening my technical toolkit, mastering new industry-standard skills, and scaling my existing expertise to a professional level.
