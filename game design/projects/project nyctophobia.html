Game Design | Nyctophobia

Nyctophobia

A first person walking sim, based around light manipulation.

Project type: Game · Role: Game Developer · Status: Released

Visit site

Overview

Nyctophobia is a short horror / walking simulator, where the player finds themselves in a pitch black ubran environment. The players find a number of tools, such as a flashlight and flares, which allow them to illuminate the environment around them.

Responsibilties

Since I worked by myself, every aspect of the game, with the exception of some audio files, required my own work. From visuals to level design and implementing the game mechanics, the project made me engage in every aspect of game development.

Outcome and Reflection

This project helped me gain more insight into the entire game development pipeline, from the concept, through development, and finally publishing on steam.I handled every aspect of the game by myself.
