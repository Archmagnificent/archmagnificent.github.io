Liminal Routine

A game jam project with a focus on Liminal Spaces

Project type: Game · Role: Gameplay Designer / Scripter · Status: Submitted

Overview

Liminal Routine is a short game with a theme of liminal spaces. The player walks through a liminal environment, in repeating loops. Each loop changes something about the level.

Responsibilties

My work on the project included:

  • working with the UE5 game engine
  • creating an implementing game mechanics
  • Overseeing technical aspects of the projects, such as managing the repository
  • Ensuring the overall functionality of the project
